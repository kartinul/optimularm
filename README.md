# optimularm

wanna wake up at the optimum time? use optimularm to wake up before ur set time that's optimum according to your sleep cycle!

## How does it work
it uses ur mac and detects when u close the lid (or if the screen dims out), whenever that happens, it calculates the estimated time of optimal sleep before a SET time....
so u always wake up ON TIME! ready w energy :) 

## How to use
download both android, mac app.
open android, mac app.
scan via qr.
use.
